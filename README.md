## Dataset and website

The dataset provides multidimensional experiential ratings for **1,985 German nouns across 16 dimensions**, together with familiarity and concreteness ratings, derived summary measures, and GermaNet semantic-field annotations.

The released data are available in the [`materials`](materials/) directory and include:

- `MultiNorms_GER_summary_level_dataset.csv` — item-level descriptive statistics, derived measures, lexical variables, and semantic annotations;
- `MultiNorms_GER_participant_level_dataset.csv` — anonymized participant-level ratings;
- `codebook.csv` — English-language variable names, labels, and descriptions.

The accompanying website provides an interactive interface for exploring the dataset, including word-level profiles, filtering, radar/bar/heatmap visualizations, dataset downloads, and access to the codebook.
