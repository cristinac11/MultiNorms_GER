# Study materials

This directory contains study materials and the datasets associated with the study:

**"A multidimensional normative database of experiential ratings for German nouns"**

## Contents

### Main datasets

- `MultiNorms_GER_summary_level_dataset.csv`  
  Contains word-level descriptive statistics and derived measures for the released German noun norms.

- `MultiNorms_GER_participant_level_dataset.csv`  
  Contains the anonymized participant-level ratings underlying the summary-level dataset.

### Test–retest materials

- `test_retest/`  
  Contains materials and data used for the longitudinal test–retest reliability analysis.

## Dataset access

The datasets can be downloaded directly from this repository.

They can also be downloaded from the accompanying project website:

**https://cristinacc11.github.io/german-nouns-norms/**

The website additionally provides an interactive interface for exploring the dataset, including word-level experiential profiles, filtering, and visualization of the rating dimensions.
